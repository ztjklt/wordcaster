# 边境瞭望防御塔 (Border Watchtower)

## 基本信息

| 属性 | 内容 |
|------|------|
| **建筑名称** | 边境瞭望防御塔 (Border Watchtower) |
| **类型** | 防御塔 / 基础防御模块 |
| **视角** | 纯2D侧视角 (Side-View) |
| **风格** | 像素风中世纪幻想 + 废弃边境聚落 + 失落文明遗迹 |
| **动画** | 无（静态建筑，单帧 Sprite） |
| **素材尺寸** | 1239 × 1846 px |

## 游戏功能

- **基础防御模块**：作为玩家可通过言灵召唤并放置的基础防御建筑
- **领地守卫**：用于守卫关键路线和资源点
- **敌人观察**：高耸结构提供广阔的视野范围
- **防御部署**：顶层瞭望平台可作为后续扩展防御武器的基础

## 建筑特点（纯2D侧视角）

- 石砖底座，三层灰色石块堆砌，表面有古文明符文
- 木质塔身，深浅棕色木板交替，垂直支撑柱
- 四个箭孔（垂直狭长开口），用于远程防御
- 顶部瞭望平台，配备木制护栏
- 红色瓦片屋顶小阁楼
- 右侧悬挂老旧破损旗帜
- 绿色藤蔓从底部两侧向上攀爬
- 铁制金属箍/铆钉加固各层连接处

## 占地大小

- **建议网格**：2×4（宽×高）
- **实际像素**：1239 × 1846 px
- **地面占地**：约 2 格宽

## 碰撞区域建议

使用**复合碰撞体 (Compound Collider)**：

| 层级 | 类型 | 范围 | 说明 |
|------|------|------|------|
| 石砖基座 | 实心方块 | 100%宽 × 22%高 | 完全实心，不可穿越 |
| 木质塔身 | 实心方块 | 85%宽 × 50%高 | 箭孔为装饰，不镂空 |
| 瞭望平台 | 单向平台 | 100%宽 × 6%高 | 可从下方跳上，顶部可站立 |
| 屋顶 | 装饰 | 无碰撞 | 纯视觉，不阻挡 |
| 藤蔓/旗帜 | 无碰撞 | — | 纯视觉装饰 |

## 是否需要动画

**不需要。** 该建筑为静态基础防御塔，仅单帧 Sprite 显示。后续扩展变体（箭塔、火焰塔等）可能需要对应动画。

## 后续扩展

该瞭望塔作为基础防御模块，可扩展为以下变体：

| 变体 | 描述 |
|------|------|
| **箭塔** | 加装箭矢发射装置，自动攻击范围内敌人 |
| **火焰塔** | 塔顶安装魔法火盆，范围火焰伤害 + 灼烧效果 |
| **能量塔** | 注入魔法能量水晶，增幅周围建筑属性 |
| **盾牌塔** | 加装护盾发生器，为周围建筑提供防御护盾 |

## 使用说明

1. 将 `sprites/watchtower.png` 导入游戏引擎作为 Sprite2D
2. 锚点设为底部中心 (bottom_center)
3. 根据 `data/object_data.json` 配置复合碰撞体
4. 该建筑为静态背景层，建议放置在地面层上方

## 注意事项

- 纯2D侧视角 Sprite，不包含3D/透视/等距效果
- 透明背景 PNG，可直接用于2D横版游戏场景
- 保持原始像素风格，引擎过滤设为 Point (Nearest)
- 像素到世界单位建议：100px = 1 单位
- 如需动画效果（旗帜飘动、藤蔓摇曳），需额外制作精灵图序列帧
