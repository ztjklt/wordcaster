# Speak to Fight

一款“英语就是操作”的手机横屏 H5 火柴人格斗垂直切片。玩家说出的英语会召唤装备、控制现实物品、治疗角色；说错近音词时，世界会真的产生荒诞误会。

## 运行

```bash
npm install
npm run dev
```

生产验证：

```bash
npm run build
npm test
```

## 已完成的游戏循环

主菜单 → 家园 → 餐厅恢复 → 战斗技能配置 → 人机战斗 → 英语结算 → 奖励成长 → 返回家园。

主要功能：

- 横屏适配、触控与键盘格斗、平台物理和敌人 AI
- OpenAI Realtime、浏览器识别与无麦克风念写三级语音通道
- 普通言灵保持正常速度，仅对手语言挑战进入子弹时间
- 盾牌、剑、治疗、击退、地图物品控制
- 霓虹神社、月雨竹林、赛博夜市、晨光厨房、温暖书房、日常地铁六套战场
- 每场 10 个命令方块名词、丰富场景句式，以及与课程严格对齐的对手挑战
- 系统 Emoji 物件、三层场景布局、代码骨骼火柴人和三段连击动画
- `shield/ship`、`sword/word`、`bread/bed`、`heal/heel`、`ice/eyes` 错误召唤
- 同义表达、语言评分、四级提示和词汇掌握度
- 对手无框限时提示与地图专属语言挑战
- 2200×1200 可探索家园、建筑碰撞、镜头前瞻、入口导航和位置恢复
- 家园支持键鼠、手柄、虚拟摇杆、体感输入和语音目的地导航
- 餐厅半自由对话、医院强化、记忆书库、休息恢复和远征入口
- 战前技能配置、独立结算、奖励、升级和 v4 存档迁移
- 语音训练场、麦克风测试、设置、新手教程和程序化音效
- v6 存档迁移、家园自动存档和 F3 调试叠层

战斗键盘操作：`A/D` 移动、`W` 跳跃、`J` 攻击、`K` 格挡。家园键盘操作：`WASD/方向键` 移动、`E/空格` 交互、`M` 切换输入、`C` 校准体感、`L` 言灵导航、`F3` 调试。手机端使用屏幕触控按钮。

## AI 实时语音

复制 `.env.example` 为 `.env` 并填写服务端 `OPENAI_API_KEY`，然后运行 `npm run dev`。浏览器只连接同源 `/api`，不会接触正式密钥。未配置 Key 时，`auto` 模式会依次降级到 Browser SpeechRecognition 和文本输入。

- `VITE_VOICE_MODE=auto|realtime|browser|mock`
- `OPENAI_INTENT_MODEL=gpt-5.4-mini`
- API 默认端口：`8787`

语音音频仅通过 WebRTC 实时传输，不落盘；学习评分始终使用原始转写，AI 修正版只用于理解自由表达。
