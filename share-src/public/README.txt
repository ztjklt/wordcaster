《Word Caster》抖音互动空间版

打开方式
========

把 ZIP 上传到抖音互动空间，入口文件为根目录的“index.html”。

互动空间内按住施法按钮会通过 tt.getRecorderManager 录制 AAC，
松开后交给 doubao-seed-2-0-lite-260428 音频模型识别英文指令。
如宿主不支持语音接口，可以打开施法魔典，在底部文字栏输入英文指令，
仍然能够完整通关。

游戏代码不会保存麦克风音频，也不会把 API Key 写入前端文件。


基本操作
========

A / D          左右移动
Space          跳跃
鼠标左键       使用短刀近战 / 使用工匠锤
鼠标右键       放置已经激活的言灵建筑
按住 M         开启麦克风
松开 M         结束并识别本次言灵
数字键 1 / 2   切换短刀和工匠锤
E / Tab        打开或关闭施法魔典
Esc            取消蓝图、关闭施法魔典或暂停

手机横屏      使用屏幕两侧战斗按钮
按住施法      等价于电脑按住 M，松开后提交转写

注意：短刀只有成功命中敌人才会扣除玩家2点生命，挥空不会扣血。


存档说明
========

游戏会把进度保存在当前浏览器和当前电脑上。

如果更换电脑、浏览器，或者清理浏览器数据，存档不会自动跟随。
每位玩家使用自己的文件夹副本和浏览器，即可拥有独立存档。


分享方式
========

上传时使用生成的 word-caster-douyin-volcengine-260428.zip。
ZIP 根目录直接包含 index.html，不要再套一层文件夹。
