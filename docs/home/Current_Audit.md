# Speak to Fight 家园系统现状审计

审计依据：`Speak_to_Fight_Home_System_Technical_Design_v1.0.docx`

## 审计时的现状

原有 `HomeScene` 是一个静态功能菜单：玩家可以点击餐厅、训练、远征和设置，但不存在可移动角色、世界坐标、碰撞、镜头跟随、空间索引、朝向交互、体感输入、手柄输入、位置恢复或家园语音导航。

现有工程已经具备可复用基础：

- Phaser 场景生命周期和 Arcade Physics。
- 餐厅、训练、远征、战斗、设置等独立场景。
- Browser / Realtime / Mock 三层语音输入。
- 玩家成长、需求、语言掌握度和版本化存档。
- 1280×720 横屏逻辑分辨率与移动端适配基础。

## 需求差距

| 模块 | 审计结果 | 本阶段处理 |
|---|---|---|
| Input | 只有各场景局部键盘/触控逻辑 | 新增统一输入模式管理器，接入键盘、手柄、虚拟摇杆和体感 |
| Player | 家园没有可控角色 | 新增平滑移动、独立朝向、状态和碰撞体分离 |
| Camera | 家园没有世界镜头 | 新增帧率无关跟随、速度前瞻和世界边界 |
| World | 家园是静态菜单 | 重构为 2200×1200 可探索 Hub World |
| Entity | 建筑与按钮直接耦合 | 建筑和入口分别数据化 |
| Interaction | 点击按钮直接跳转 | 新增距离、朝向、优先级评分和统一执行 |
| Functional Scenes | 缺少医院与书架 | 新增生命诊所和记忆书库 |
| Voice Bridge | 语音只服务战斗 | 新增解耦的家园目的地解析与导航桥 |
| Save | 不保存家园状态 | 存档升级到 v6，加入迁移、位置、朝向、输入和调试状态 |
| Debug | 无家园调试信息 | 新增 FPS、输入源、坐标、速度、碰撞与网格叠层 |

## 风险与约束

- Phaser 全局物理重力用于横版战斗，家园角色必须单独禁用重力。
- iOS 体感权限只能由用户手势请求，不能在场景加载时自动弹窗。
- 语音导航必须复用既有语音提供方，家园模块不能直接依赖某个浏览器 API。
- 旧存档没有 `home` 字段，迁移必须提供安全出生点并限制非法坐标。
- 移动端横屏空间有限，触控按钮、导航信息和交互提示必须使用固定屏幕坐标。
